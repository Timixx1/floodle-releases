## ✨ Desktop-Exclusive Features

### 🖥️ System Integration
- **System Tray** — Icon in your taskbar notification area
- **Native Notifications** — Windows toast notifications for messages
- **Auto-start** — Launch Floodle when Windows starts (optional)
- **Minimize to tray** — App stays in background without cluttering taskbar

### ⚡ Performance
- **Offline caching** — Access recent notes without internet
- **Faster load times** — Pre-loaded assets and local storage
- **Smooth animations** — Hardware-accelerated rendering

### 🔒 Security
- **Secure storage** — Local encryption for offline data
- **No browser extensions** — Reduced attack surface
- **Isolated session** — Separate from browser cookies/history

## 🔧 Installation

### Standard Setup (Recommended)

1. **Download** the installer:  
   [Floodle-Setup-1.0.1.exe](https://github.com/Timixx1/floodle-releases/releases/latest/download/Floodle-Setup-1.0.1.exe)

2. **Run the installer** — Double-click the downloaded file

3. **Follow the setup wizard:**
   - Choose installation directory (default: `C:\Program Files\Floodle`)
   - Select start menu folder
   - Optional: Create desktop shortcut

4. **Launch Floodle** from Start Menu or Desktop


## 🚀 First Launch

1. **Sign in** with your existing Floodle account
2. **Or create** a new account from the app
3. **Enable notifications** when prompted for the best experience
4. **Start using** all Floodle features:

| Feature | Desktop Access |
|---------|----------------|
| 📝 Notes | Click Notes icon or press `Ctrl+N` |
| 💬 Chat | Click Chat icon or press `Ctrl+C` |
| 🎨 Canvas | Open any note with canvas |
| 📋 Paste | Click Paste icon |
| 🧠 AI | Click AI icon or press `Ctrl+A` |
